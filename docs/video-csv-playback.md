# 本地视频与 CSV 时间轴

在“视频”页选择本地视频，导入该视频的 CSV，再准备会话并使用播放器播放。
视频由浏览器原生播放器解码；是否支持某个容器和编码取决于浏览器，不进行转码。
首版固定 1 倍速。每个视频按文件内容标识关联自己的 CSV。

CSV 使用 UTF-8，必须包含下面四列：

```csv
start_time,end_time,A_target,B_target
0:10:20,0:11:30,30,15
0:12:00,0:12:40,20,0
```

时间是相对视频起点的绝对时间 `小时:分钟:秒`，不是区间长度。
例如第一行从第 10 分 20 秒开始，在第 11 分 30 秒结束。
开始时刻包含在区间内，结束时刻不包含。没有覆盖的部分两个通道均为 0。
表格软件中请将时间列设为文本，避免导出成日期、小数或带 AM/PM 的时间。
区间必须按时间排序、不重叠、结束晚于开始且不超出视频长度；错误的 CSV 不会进入播放。
CSV 强度是 0–200 的整数，0 表示停止该通道。

每行开始时为两个通道分别随机选择允许的波形，每 30 秒换一个。
行尾不足 30 秒的部分截断；有多个波形时不连续选择相同波形。
整条随机时间轴在会话开始前确定，跳回同一位置会选择本次会话原来的波形。
重新准备会话会产生新的随机结果。视频模式持续循环波形，不加入小说模式的随机周期间歇。

输出始终经过当前安全规则。页面分别显示 CSV 目标、上限裁剪后的目标与已确认输出。
不会自动提高设备或本地配置中的强度上限。
视频模式不使用缓升。强度直接到达 `min(CSV 目标, 当前通道有效安全上限)`；
上升、下降、定位后继续播放和暂停后恢复均采用同一规则，实际输出以成功确认为准。
以下示例假设当前有效安全上限为 40；该数值仅用于举例，不会写入或提高本地配置：

| 变化 | 执行方式 |
| --- | --- |
| 20 → 30 | 直接到 30 |
| 0 → 30 | 直接到 30 |
| 20 → 31 | 直接到 31 |
| 0 → 60 | 目标裁剪为 40，直接到 40 |

同一目标持续播放或更换随机波形不会重复发送强度命令。
暂停、定位、等待缓冲、结束、错误、连接断开或时钟失联都会清零。
播放中定位完成后可继续跟随新位置；暂停时定位不会自动播放。
急停和安全清零优先于视频输出。

## 离线验证

先构建前端，再启动只使用临时数据和模拟中继的独立测试服务。
在拥有本地 `.venv` 和可用 Node 的完整项目目录中执行：

```powershell
npm --prefix frontend run build
.\.venv\Scripts\python.exe -m tests.video_browser_harness --port 9081
```

本次独立工作树没有自己的 `.venv` 或 `.runtime/node`。在该工作树目录中，
可以复用本机已安装的依赖；这些命令只启动独立模拟服务，不启动母目录后端：

```powershell
$env:PATH = 'D:/AI-for-Coyote/.runtime/node/node-v24.19.0-win-x64;' + $env:PATH
npm --prefix frontend run build
& 'D:/AI-for-Coyote/.venv/Scripts/python.exe' -m tests.video_browser_harness --port 9081
```

打开 `http://127.0.0.1:9081/`，使用合成视频和 CSV 测试。
`/__synthetic_check` 应显示 `dry_run: true` 和 `sent_frames: 0`。
该服务不启动真实中继或模型调用，也不加载用户运行配置。
开发服务器的 `/api` 代理同时启用 WebSocket，以支持视频播放时钟。

本次离线验收与实机验收分开。实机行为尚需用户在现有安全限制下手动验证，
离线通过不代表已经部署或完成实机验收。
